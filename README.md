# WeComGroupRpa releases

This public repository only hosts portable installer packages for [WeComGroupRpa](https://github.com/hungry557/WeComGroupRpa). It does not contain source code.

Download `wecom-group-rpa-<version>.zip` and `SHA256SUMS.txt` from [Releases](https://github.com/hungry557/WeComGroupRpa-releases/releases). No GitHub login or `gh` token is required.
